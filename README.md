# YouTube No-Cookie Redirect - Opera/Chrome Browser Extension

A browser extension for Opera that adds a custom option to the right-click context menu on YouTube, allowing you to watch videos on youtube-nocookie.com (ad-free and privacy-enhanced version).

## Features

- Adds a "Watch on youtube-nocookie.com" option to the right-click menu on YouTube videos
- Automatically redirects to the privacy-enhanced version of YouTube
- No tracking cookies or ads on the redirected version
- Easy one-click access to ad-free viewing

## Installation

1. Download or create all the required files:
   - `manifest.json`
   - `background.js`
   - `content.js`
   - Extension icons (`16.png`, `48.png`, `128.png`)

2. Open Opera and navigate to `opera://extensions` or Chrome `chrome://extensions`

3. Enable "Developer mode" using the toggle in the top right corner

4. Click the "Load unpacked" button

5. Select the folder containing your extension files

6. The extension will now be installed and active

## Usage

1. Navigate to any YouTube page
2. Right-click on a video or video link
3. Select the "Watch on youtube-nocookie.com" option from the context menu
4. You will be redirected to the ad-free, privacy-enhanced version of the video
